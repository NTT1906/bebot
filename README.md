# Bebot

Bebot is a Minecraft Bedrock bot written in Go using the `gophertunnel` framework.

## Requirements

- [Go](https://golang.org/dl/) 1.21 or higher

## Configuration

Before running the bot, configure the `config.json` file in the project root. If the file doesn't exist, create it based on this structure:

```json
{
  "_comment": "Edit this file to configure the bot.",
  "superuser": "YourUsername",
  "_comment_superuser": "Only this player can control the bot via chat commands.",
  "server": {
    "host": "your.server.ip",
    "port": 19132,
    "version": "1.20.0"
  },
  "skin": {
    "type": "slim",
    "path": "skin/skin.png",
    "skin": "0",
    "override": false
  },
  "target": {
    "x": 0,
    "y": 64,
    "z": 0
  },
  "behaviour": {
    "reconnectBaseDelayMs": 5000,
    "afkJumpIntervalMs": 60000,
    "walkSpeed": 0.15,
    "renderDistance": 5
  },
  "commands_via_chat": false
}
```

- **`superuser`**: Your Minecraft username. Only you will be able to issue commands to the bot.
- **`server`**: Set the `host`, `port`, and expected bedrock `version` of the server.
- **`skin`**: Set a custom skin. You can define the type (`slim`, `normal`) and point to a local `.png` or folder path.
- **`behaviour`**: Tweaks for how the bot operates in-game (like how often to jump to prevent AFK kicks).

## Usage

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Configure your `config.json`.
4. Run the bot directly using Go:

```bash
go run .
```

Alternatively, build the binary:

```bash
go build -o bebot.exe .
./bebot.exe
```

### Joining a Local / Single-Player World (LAN)

To have the bot join your local single-player Bedrock world:

1. Open your world in Minecraft Bedrock.
2. In game settings, ensure **Multiplayer Game** and **Visible to LAN Players** are enabled.
3. Run the bot with the `-local` flag:
   ```bash
   .\bebot.exe -local
   ```
   *(By default, `-local` uses offline/LAN mode so it doesn't conflict with your active player account, connects to `127.0.0.1:19132`, and auto-discovers ports 19133-19140 if the primary port was taken).*

### Command-Line Arguments

* **`-local`**: Connects to a local/LAN single-player world on `127.0.0.1`.
* **`-offline`**: Connects in offline/LAN mode without requiring Microsoft Live authentication.
* **`-name <name>`**: Sets the bot's username in offline/LAN mode (default: `Bebot`).
* **`-host <host>`**: Overrides the target server host (e.g. `127.0.0.1` or LAN IP `192.168.1.5`).
* **`-port <port>`**: Overrides the target server port (e.g. `19132`).
* **`-config <file>`**: Path to custom config file (default: `config.json`).
* **`-skin <file>`**: Path to custom skin config file (default: `skin.json`).
* **`-debug`**: Prints packet-level diagnostics.

When you first run the bot, it will prompt you for Microsoft Live / Xbox authentication. Follow the OAuth link provided in the console to authorize the bot's account.

Once connected, join the server on the same server to see the bot. If you are the `superuser`, you can issue commands directly to it in-game via chat!

## Commands

Commands can be typed in the console or sent via in-game whisper (`bebot <command>`):

* **`mine <ax> <ay> <az> <bx> <by> <bz> [ticks] [continuous: true|false]`** (or `mineloop` / `minefarm`): Mines all blocks in the cuboid defined by corners A and B. Mining progresses top-down in an efficient serpentine pattern. The bot automatically walks toward out-of-reach blocks and faces each block while swinging its arm.
  * **Dynamic Block Detection**: Any new block appearing in the area (e.g. pushed by a piston, generated by a cobblestone generator, or placed by a player) is automatically detected via server `UpdateBlock` packets and queued to be mined.
  * **`continuous` / `mineloop`**: Stays in the area and continuously mines blocks as they regenerate or are pushed in (ideal for cobblestone/stone generators and piston farms).
  * Optional `[ticks]`: Custom break duration in ticks per block (default: 2 ticks in creative mode, 40 ticks in survival).
* **`stopmine`** / **`stopbreak`** / **`stop`**: Cancels active mining and stops movement.
* **`break <x> <y> <z> <animate: true|false> [repeat: true|false]`**: Breaks a single block at the given position.
* **`move <x> <y> <z>`**: Moves the bot to the specified coordinates.
* **`follow <player>`**: Follows a player.
* **`lookat [player|<x y z>]`**: Turns to look at a player or coordinate.
* **`hotbar <0-8>`**: Selects a hotbar slot.
* **`dropall`** / **`drop <slot> [amount]`**: Drops items.
* **`say <message>`**: Sends a chat message.
